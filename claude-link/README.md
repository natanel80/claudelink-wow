# ClaudeLink: ‏Claude רואה את המשחק בזמן אמת

ClaudeLink מחבר את WoW Forever ל-Claude. בזמן שאתם משחקים אפשר לשאול את Claude למשל "מה לעשות עכשיו?" או "למה מתתי?", והוא רואה מה קורה אצלכם במשחק באותו רגע.

**הכל לקריאה בלבד.** התוסף והשרת רק קוראים מידע. הם לא לוחצים על מקשים ולא משחקים בשבילכם, כי אחרת זה בוט, ועל זה אפשר לקבל באן.

## איך זה עובד

תוסף של WoW לא יכול לכתוב לקבצים או לשלוח מידע החוצה בזמן שהמשחק רץ, אז ClaudeLink משתמש בשלוש דרכים:

1. **פס צבעוני בפינת המסך.** התוסף מצייר בפינה השמאלית העליונה פס קטן של ריבועים צבעוניים (בערך 144×24 פיקסלים) ומעדכן אותו עשר פעמים בשנייה. כל צבע מייצג נתון: חיים, מאנה, מטרה, החיה, באפים, cooldowns, הקרב הנוכחי ועוד. השרת קורא את הפס מהמסך ארבע פעמים בשנייה.
2. **דוח מלא.** ספר הכישורים, התיקים, הקווסטים, הציוד, ה-Talents, 30 הקרבות האחרונים ו-20 המיתות האחרונות. הדוח נשמר בכל `/reload` וביציאה מהמשחק.
3. **יומן הקרבות של המשחק.** קובץ `Logs\WoWCombatLog.txt`, עם כל מכה ומכה. מדליקים אותו פעם אחת עם הפקודה `/combatlog` במשחק.

## מה WoW Forever לא מרשה לתוספים

WoW Forever עובד עם אותן הגבלות כמו הגרסה החדשה של WoW (Midnight), ו-ClaudeLink עומד בהן:

- **אסור לקרוא את אירועי הקרב.** ClaudeLink לא קורא אותם. את הנזק בכל קרב Claude לוקח מקובץ יומן הקרבות שהמשחק עצמו כותב (`/combatlog`).
- **בקרב המשחק מסתיר מספרים** כמו החיים שלכם ושל המטרה, ואסור לתוסף לחשב איתם. ClaudeLink רק מציג אותם בפסים קטנים מתחת לריבועים, וזה מותר, והשרת מודד כמה כל פס מלא. ככה Claude יודע את אחוזי החיים גם בקרב.
- **אסור אוטומציה.** הכל לקריאה בלבד, ו-Claude רק נותן עצות.

## מה Claude יכול לעשות

| כלי | מה הוא נותן |
|---|---|
| `get_live_state` | המצב עכשיו: חיים, מאנה, המטרה (רמה, חיים, את מי היא תוקפת, דיבאפים), החיה, באפים, כל היכולות בבר עם cooldown ו"מוכן/לא מוכן", הקרב הנוכחי, זהב, תחמושת, מקום במפה |
| `get_recent_events` | מה קרה בדקות האחרונות: כניסה ויציאה מקרב, מיתות ומי הרג אתכם, החיה מתה, חיים נמוכים, הודעות שגיאה כמו "Target too close", עליית רמה |
| `get_health_timeline` | חיים ומאנה שנייה אחרי שנייה, כדי להבין איך הלך קרב |
| `get_full_report` | הדוח המלא |
| `get_quest_guide` | לכל קווסט: מי נותן אותו, איפה מחזירים, ואיפה נמצאים המובים, החפצים והפריטים שצריך (לפי Questie) |
| `get_combat_log` | השורות האחרונות מיומן הקרבות |
| `take_screenshot` | צילום של חלון המשחק |
| `get_link_status` | בדיקה שהחיבור עובד |
| `get_notes` / `save_note` | הערות שנשמרות בין שיחות: תוכניות, החלטות, דברים שחשוב לזכור |

## מידע מתוספים אחרים

אם התוספים האלה מותקנים, ClaudeLink מעביר גם את המידע שלהם. אם תוסף לא מותקן, פשוט מדלגים עליו.

| תוסף | מה Claude מקבל | מתי מתעדכן |
|---|---|---|
| Hekili / Hekili Forever | שלוש היכולות הבאות שהוא ממליץ | בזמן אמת |
| Deadly Boss Mods | טיימרים של בוסים ואזהרות | בזמן אמת |
| Questie | איפה המובים, החפצים והפריטים של כל קווסט, ואיפה מחזירים אותו | ב-`/reload` |
| Auctionator | מחיר במכירות הפומביות לכל פריט בתיקים | ב-`/reload` |
| Pawn | אילו פריטים בתיקים הם שדרוג, ובכמה אחוזים | ב-`/reload` |
| Bartender4 או הברים הרגילים | איזה מקש לוחצים לכל יכולת, כדי ש-Claude יוכל לכתוב "לחץ 2" | ב-`/reload` |

הדוח המלא כולל גם רשימה של כל התוספים שמופעלים אצלכם.

**חשוב:** Claude עונה כשאתם שואלים. הוא לא קופץ לבד באמצע קרב.

## התקנה כתוסף לאפליקציית Claude (הכי פשוט, עובד גם ב-Chat רגיל)

צריך Python 3.10 ומעלה מ-[python.org](https://www.python.org/downloads/). בהתקנה מסמנים **Add python.exe to PATH**.

1. מורידים את הקובץ [`wow-forever-link.mcpb`](https://github.com/natanel80/claudelink-wow/raw/main/claude-link/dist/wow-forever-link.mcpb).
2. לוחצים עליו פעמיים. אפליקציית Claude נפתחת ושואלת אם להתקין. מאשרים.
3. בוחרים את תיקיית `_forever_` של המשחק, אם היא לא נבחרה לבד.

בהפעלה הראשונה התוסף מתקין לבד את מה שהוא צריך (בערך דקה), ומעתיק את ClaudeLink לתיקיית המשחק. אחר כך ב-WoW כותבים `/reload`, ושואלים את Claude: "תבדוק את החיבור למשחק שלי".

אם התקנתם בעבר עם `setup.ps1`, מוחקים קודם את `"wow-forever"` מקובץ ההגדרות של Claude, כדי שלא ירוצו שני שרתים.

### עדכונים אוטומטיים

בכל הפעלה התוסף בודק אם יש גרסה חדשה ב-GitHub (`natanel80/claudelink-wow`, ענף `main`). אם יש, הוא מוריד אותה ומעדכן גם את ClaudeLink בתיקיית המשחק. מספיק לסגור ולפתוח את אפליקציית Claude, ואחר כך `/reload` במשחק.

- ה-repo ציבורי, אז לא צריך שום token.
- אפשר לכבות עדכונים בהגדרות התוסף (**Automatic updates**).

## התקנה כפלאגין (ל-Cowork ול-Claude Code)

צריך Python 3.10 ומעלה מ-[python.org](https://www.python.org/downloads/). בהתקנה מסמנים **Add python.exe to PATH**.

הפלאגין כולל גם את הסקילים, אבל הכלים שלו עובדים רק ב-**Cowork** או בלשונית **Code**, לא ב-Chat רגיל.

**באפליקציית Claude למחשב:**
1. **Customize** ← **Plugins** ← **Add** ← **Add marketplace**, ומדביקים: `natanel80/claudelink-wow`
2. מתקינים את הפלאגין **wow-forever-link**.

**ב-Claude Code:**
```
/plugin marketplace add natanel80/claudelink-wow
/plugin install wow-forever-link@wow-forever
```

בהפעלה הראשונה הפלאגין מתקין לבד את מה שהוא צריך (בערך דקה), ומעתיק את התוסף ClaudeLink לתיקיית המשחק. אם WoW מותקן במקום אחר מ-`C:\Program Files (x86)\World of Warcraft\_forever_`, משנים את התיקייה בהגדרות הפלאגין.

אחר כך:
1. מפעילים את WoW. במסך הדמויות, ב-AddOns, מוודאים ש-ClaudeLink מסומן.
2. במשחק כותבים `/claudesync` ואחר כך `/reload`.
3. שואלים את Claude: "תבדוק את החיבור למשחק שלי".

## התקנה בלי פלאגין (setup.ps1)

אם אתם לא משתמשים בפלאגינים, אפשר להתקין עם סקריפט:

1. מורידים את התיקייה `claude-link` למחשב.
2. פותחים PowerShell בתוך התיקייה ומריצים:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1
   ```

   הסקריפט מעתיק את התוסף ל-`_forever_\Interface\AddOns\ClaudeLink`, מתקין את השרת ומחבר אותו לאפליקציית Claude. הקובץ הקודם של ההגדרות נשמר עם הסיומת `.before-claudelink`.
3. סוגרים את Claude לגמרי, כולל מהאייקון ליד השעון, ופותחים מחדש.

## פקודות במשחק

| פקודה | מה היא עושה |
|---|---|
| `/claudelink status` | האם התוסף עובד |
| `/claudelink hide` / `show` | מכבה או מדליק את הפס |
| `/claudelink corner tl` / `tr` / `bl` / `br` | מעביר את הפס לפינה אחרת |
| `/claudelink size 4` | ריבועים גדולים יותר, אם יש שגיאות קריאה |
| `/combatlog` | מדליק או מכבה את יומן הקרבות. זו פקודה של המשחק עצמו, כי WoW Forever לא מרשה לתוסף לעשות את זה |
| `/claudesync` ואז `/reload` | שומר את הדוח המלא עכשיו. WoW Forever לא נותן לתוסף לעשות reload לבד, אז כותבים `/reload` בעצמכם |

## אם משהו לא עובד

- **"The ClaudeLink strip was not found"**: הפינה של המשחק מוסתרת. אם החלון של Claude מכסה אותה, הזיזו אותו או העבירו את הפס לפינה אחרת עם `/claudelink corner tr`. הכי נוח: Claude על מסך שני או בטלפון.
- **"checksum mismatch"**: משהו משנה את הצבעים בדרך למסך, למשל פילטר צבעים של כרטיס המסך, HDR או ReShade. כבו אותו, או נסו `/claudelink size 4`.
- **המשחק ממוזער**: השרת לא יכול לקרוא את הפס כשהחלון ממוזער. מצב Windowed (Fullscreen) עובד הכי טוב.
- **Claude לא רואה את הכלים**: סגרו את Claude לגמרי ופתחו מחדש. אם עדיין לא עובד, הריצו שוב את `setup.ps1`.

## למפתחים

- `addon/ClaudeLink`: התוסף (Lua).
- `server`: שרת ה-MCP (Python).
- `extension`: התוסף לאפליקציית Claude. בונים אותו עם `python claude-link/extension/build.py`, והוא נוצר ב-`dist/wow-forever-link.mcpb`.
- הפורמט של הפס מוגדר ב-`addon/ClaudeLink/Live.lua` וב-`server/wowlink/protocol.py`, ושני הקבצים חייבים להתאים זה לזה.
- הבדיקות מריצות את קוד התוסף האמיתי מול משחק מדומה, מציירות את הפס לתמונה ומוודאות שהשרת קורא אותו נכון:

  ```bash
  pip install lupa pillow pytest mcp
  pytest server/tests
  ```
