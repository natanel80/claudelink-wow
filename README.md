# ClaudeLink for WoW Forever

ClaudeLink lets Claude see your WoW Forever character while you play: health, target, pet, cooldowns, buffs, quests, bags and more. Ask "what should I press now?" or "why did I die?" and Claude answers from what is happening in your game.

It is **read-only**. It never presses keys or plays for you, and it follows WoW Forever's addon rules (no combat log access, no math on hidden "secret" values).

**Install (Windows, Claude desktop app):** download [`wow-forever-link.mcpb`](https://github.com/natanel80/claudelink-wow/raw/main/claude-link/dist/wow-forever-link.mcpb) and double-click it. You need Python 3.10+ from python.org. It installs the ClaudeLink addon into your game and updates itself from this repository.

Full instructions (Hebrew): [claude-link/README.md](claude-link/README.md)
